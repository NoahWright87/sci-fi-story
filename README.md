# sci-fi-story

Repo for finally writing down a story I've been building in my head since I was a teenager.

A working world bible for a multi-generational science-fiction universe, originally imagined through several different game concepts. The immediate goal is to preserve the author's ideas and develop them through conversation, not to force them into a novel.

## Workflow
- `human-input/`: author-authored notes, never rewritten by AI without explicit instruction
- `lore/`: author-established facts with unresolved details clearly labeled
- `proposals/`: AI-generated suggestions, not canon
- `stories/`: outlines and prose drafts, not canon unless approved
- [AGENTS.md](AGENTS.md): instructions for ChatGPT, Claude Code, Codex and other agents

**Established** means the author said it. **Open** means not decided. **Proposed** means AI suggested it. All imported material is a paraphrase of prior conversation, not a verbatim record; the author should review and correct it.
